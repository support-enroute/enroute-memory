ENROUTE MEMORY GAME — STATIC WEBSITE

Upload index.html, style.css, game.js and the entire assets folder to your web server's public directory (for example public_html, www, or htdocs).
Keep the files together and preserve the assets folder structure.
Open your domain or the subfolder URL to play.

No installation, build step, Node.js, backend, database, or API keys are required.
All fonts, illustrations, and the logo are included locally.
Scores are saved in each browser using localStorage; scores from the old domain do not transfer automatically.

Sharing metadata already uses Enroute Memory Game. Optionally add an og:url meta tag in index.html with your new public URL.
